## 🧪 How to Test Notifications

### **Option 1: Using the Test Screen (In-App)**

1. **Launch the App**
   ```bash
   flutter run
   ```

2. **Open Notification Tester**
   - Tap the **🔔 bell icon** in the top-right corner of the home screen

3. **Check Status**
   - View FCM Token (will show "Not available" on iOS Simulator)
   - Check permissions status
   - See scheduled notifications count

4. **Test Immediate Notification**
   - Tap "📱 Test Immediate Notification"
   - Check your notification center
   - Should appear immediately

5. **Schedule Recurring Notifications**
   - Tap "📅 Schedule All" to set up all daily notifications
   - OR tap individual buttons to schedule specific ones
   - Check the "Scheduled" count to verify

6. **Monitor Activity Log**
   - Scroll down to see real-time logs
   - All actions are logged with timestamps

### **Option 2: Testing Push Notifications (Real Device Only)**

1. **Get Your FCM Token**
   - Open Notification Tester
   - Copy the FCM Token from the status card
   - Send it to your backend or use Firebase Console

2. **Send Test Message from Firebase Console**
   - Go to Firebase Console → Cloud Messaging
   - Click "Send your first message"
   - Enter title and body
   - Under "Target", select "FCM registration token"
   - Paste your token
   - Send the message

3. **Test Scenarios**
   - **App in foreground**: Message logs in console
   - **App in background**: Notification appears in system tray
   - **App terminated**: Notification appears, tapping opens app

## 🎯 Notification Scheduling

```dart
await LocalNotificationService().scheduleMorningReminder();
```

### **Daily Challenge (12:05 AM)**
```dart
await LocalNotificationService().scheduleDailyChallenge();
```
- Repeats daily at 12:05 AM local time

### **League Reminder (11 AM)**
```dart
await LocalNotificationService().scheduleLeagueReminder();
```
- Repeats daily at 11:00 AM local time

### **Comeback Bonus (On-Demand)**

## 📝 How Notifications Work in MindRush

### **On App Launch (main.dart)**
```dart
// Firebase initialization
await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);

// FCM initialization
await FCMService().initialize();

// Local notifications initialization
await LocalNotificationService().initialize();
```

### **Permission Flow**
1. App launches → Services initialize
2. FCM requests notification permissions (iOS)
3. User grants/denies permissions
4. Token is generated (if granted)
5. Token sent to backend (for targeted push notifications)

### **Scheduling Flow**
1. User interacts with app (daily login, quest completion, etc.)
2. Retention logic checks if notifications should be scheduled
3. Local notifications scheduled based on user timezone
4. Notifications fire at specified times
5. User taps notification → App routes to specific screen

## 🐛 Troubleshooting

### **"FCM Token not available"**
- **Cause**: Running on iOS Simulator
- **Solution**: Test on real iPhone or ignore (local notifications still work)

### **"Notifications not appearing"**
- **Check 1**: Verify permissions are granted (Settings → MindRush → Notifications)
- **Check 2**: Check "Do Not Disturb" is off
- **Check 3**: Verify app is not terminated by system
- **Check 4**: Check notification scheduling was successful (use test screen)

### **"App crashes on launch"**
- **Cause**: Firebase configuration missing
- **Solution**: Run `flutterfire configure` and rebuild

### **"Notification doesn't open correct screen"**
- **Cause**: Deep linking not configured
- **Solution**: Implement notification router (placeholder exists in code)

## 🎨 Customization

### **Change Notification Times**
Edit in `lib/services/local_notification_service.dart`:

```dart
// Morning reminder - change hour
var scheduledDate = tz.TZDateTime(tz.local, now.year, now.month, now.day, 8, 0);

// Daily challenge - change hour and minute
var scheduledDate = tz.TZDateTime(tz.local, now.year, now.month, now.day, 0, 5);

// League reminder - change hour
var scheduledDate = tz.TZDateTime(tz.local, now.year, now.month, now.day, 11, 0);
```

### **Change Notification Content**
Edit notification titles and bodies in the same file:

```dart
await _notifications.zonedSchedule(
  morningReminderId,
  '🌅 Your Custom Title',  // Change this
  'Your custom message',    // Change this
  scheduledDate,
  // ... rest of config
);
```

### **Add New Notification Types**
1. Create new notification ID constant
2. Add scheduling method in `LocalNotificationService`
3. Add button in `NotificationTestScreen`
4. Test thoroughly

## 🎓 Best Practices

1. **Don't Spam Users**
   - Limit notifications to important events
   - Allow users to configure notification preferences

2. **Respect Timezone**
   - All scheduled notifications use user's local timezone
   - Morning reminders at 8 AM local time, not server time

3. **Handle Permissions Gracefully**
   - Don't request permissions immediately on first launch
   - Explain value before requesting permissions
   - Provide fallback functionality if denied

4. **Test Thoroughly**
   - Test on both iOS and Android
   - Test in all app states (foreground, background, terminated)
   - Test timezone changes
   - Test permission denial scenarios

5. **Monitor Performance**
   - Track notification open rates
   - Monitor battery impact
   - Check for notification fatigue

## 🔐 Security Notes

- ✅ FCM tokens are device-specific and automatically refreshed
- ✅ Tokens should be sent to backend over HTTPS
- ✅ Never expose Firebase server key in client code
- ✅ Use Firebase Cloud Functions for server-side notification sending
- ✅ Validate all notification payloads on server
